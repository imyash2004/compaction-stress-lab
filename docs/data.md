# Data: where everything comes from

Three sources, one per evidence layer. **What is committed:** the exact inputs used, in [`inputs/`](../inputs/README.md)
(the 12 real sessions with their questions, the 10 live bugs, the safety verdicts), and the aggregated results in
[`findings/data/`](../findings/data/). **What is not:** the raw downloads and the per-run outputs (`data/`, `runs/`,
`results/`). They are regenerated by the code, as described below.

| Layer | Source | License | Fetched / built by | Local folder |
|---|---|---|---|---|
| 1 · Controlled lab | Generated: a scripted production-outage session | (ours) | `python -m lab.run build` (or on demand) | `transcripts/` |
| 2 · Real sessions | Hugging Face [`nebius/SWE-agent-trajectories`](https://huggingface.co/datasets/nebius/SWE-agent-trajectories) | CC-BY-4.0 | `python -m lab.replay fetch` then `build` | `data/replay/`, `data/cases/` |
| 3 · Live agent | Hugging Face [`princeton-nlp/SWE-bench_Verified`](https://huggingface.co/datasets/princeton-nlp/SWE-bench_Verified) + the real GitHub repos | dataset and repos under their own licenses | `python -m lab.live.tasks select`, `build`, `validate` | `data/live/` + Docker images `csl-live:*` |

## Layer 1 · The lab session (generated)

`lab/scenario.py` holds the story (4 parts), the 29 facts with their traps, the 8 recorded decisions and the rollout
rules. `lab/noise.py` generates realistic tool output (logs, tracebacks, pip, kubectl, pytest, git). `lab/transcript.py`
assembles them into one session per noise level and seed. It is deterministic: the same seed always gives the same
session. 3 noise levels × 3 seeds (7, 11, 13) = 9 sessions of 44k–225k tokens.

## Layer 2 · Real recorded sessions (downloaded)

`lab/replay.py fetch` pages through the dataset's public API (no account needed) and caches rows in `data/replay/raw/`
(this study scanned about 17,000 rows and cached 167 candidates). `build` selects 12 resolved sessions from 12 repositories, converts
them to native tool calls, cuts them before the end, splits them into 4 parts and writes the questions and answers
(see [`prompts.md`](prompts.md#question-writer-for-real-sessions)) to `data/cases/b-<task>.json`.

Each case file holds the converted session (`phases`), the hidden remainder (`hidden`), the answer key (`key`: files
edited, next step, questions with exact answers and where they appear, why-questions with references) and its
provenance (dataset row, original model, license).

## Layer 3 · Real GitHub bugs (downloaded + built)

`lab/live/tasks.py` selects 10 bugs from SWE-bench Verified, builds one Docker image per bug with the
repository at the commit just before the real fix, and validates that the hidden tests fail before the fix and pass
with it. Details per bug: [`live-tasks.md`](live-tasks.md).

| File | Contents |
|---|---|
| `data/live/verified.json` | The SWE-bench Verified rows scanned |
| `data/live/candidates.json` | 16 candidates (repo, base commit, issue text, gold patch, test patch, test names) |
| `data/live/validation.json` | Per candidate: hidden tests fail before / pass after the real fix |
| `data/live/tasks.json` | The 10 bugs used (issue text, hidden tests, test command, image name) |

## Run outputs (local)

| Folder | One folder per run, containing |
|---|---|
| `runs/a/<run>/`, `runs/b/<run>/` | `meta.json` (settings, status), `compaction_round_<k>.json` (API response incl. usage), `summary_round_<k>.txt` (Claude's readable summary), `probe_<quiz/state/action>.json` (the model's answers), `scores.json` |
| `runs/c/<run>/` | `meta.json`, `trace.jsonl` (every step: tool calls and outputs), `compaction_round_<k>.json`, `final_message.txt`, `diff.patch` (the agent's code change), `eval.json` (hidden-test result), `metrics.json` |
| `results/` | `items_a.jsonl`, `items_b.jsonl` (one row per scored answer), `runs_c.jsonl` (one row per live run) |

Run ids read like `openai-gpt-6-luna-medium-pytest-dev__pytest-7571-compact-c6000-rep1`: model, effort, task,
strategy, compaction pressure, attempt.

## From raw runs to the committed results

```bash
python -m lab.study score --layer a|b   # answers -> scores (+ judge) -> results/items_*.jsonl
python -m lab.live.agent collect        # live runs -> results/runs_c.jsonl
python -m lab.aggregate                 # -> reports/data/summary.json
python -m lab.figures                   # -> reports/charts/
python -m lab.findings                  # -> findings/ (committed)
python -m lab.docs                      # -> docs/ (committed)
```
